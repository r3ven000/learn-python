When using the if-else construct, exactly one branch will always be executed. The following figure shows the structure:

<img width="538" height="697" alt="изображение" src="https://github.com/user-attachments/assets/86271191-a3c0-4894-9969-8dea5f85ebc3" />

A conditional statement can be added using the elif branch.
This is short for "else if," meaning that the branch will contain an alternative to the original condition. 
It's important to note that the elif statement is only executed if none of the previous branches are satisfied.

### Logical Operators
You can combine conditions with the logical operators and and or.
The and operator specifies that all specified conditions must be met simultaneously. 
The or operator specifies that at least one of the specified conditions must be true.
